# McDonald 卡牌生成规范

后续生成或修改 McDonald 卡牌时，必须先读取本文件，并遵守以下四条原则。适用于本目录中的卡面、图案素材及其导出文件。

## 1. 除图案外，其他部分不得改动

- 复用已确认卡牌的 McDonald 字样与边框，保留原有位置、尺寸、颜色和像素细节。
- 卡片画布、底色和留白区域也保持不变；只修改本次指定的图案区域。
- 使用保留固定底板的合成流程，不让图像生成工具重新绘制整张卡的文字和边框。

## 2. 同一图形只生成一次，其余复制使用

- 一张卡中重复出现的同一图形，只制作一个原始图案，其余实例直接复制该图案。
- 需要倒置时，对副本旋转 180°，不得分别生成、重画或使用左右镜像代替旋转。
- 所有副本保持一致的形状、尺寸、颜色、纹理和像素细节。保存原始图案，便于后续复用。

## 3. 图形方向严格遵循卡牌模板

- 数量、位置以及每个图形朝上或朝下的方向，均以用户指定的卡牌模板为准，不自行推断或改排。
- 例如：3 牌中，1 个图形向上、2 个图形向下。这里的“1”和“2”表示数量，不是图形序号；具体位置按模板确认。
- 制作前明确每个图案实例的位置及方向；缺少模板且无法确定时，先向用户确认。

## 4. 交付可编辑的 Aseprite 文件

- 用户已明确允许复用此前的脚本制作方法：可以用脚本确定性合成、复制和旋转素材，写出标准 Aseprite 文件，不要求安装或运行 Aseprite 软件。也可以在 Aseprite 中直接制作。
- 将固定底板（McDonald 字样、边框及背景）与图案分层保存；重复图案由同一素材复制，便于独立调整位置和方向。
- 交付可编辑的 `.aseprite` 源文件及由相同图层合成的 PNG。
- 仅把整张生成图导入并保存为单图层 `.aseprite`，不算满足本条要求。
- 如采用脚本写文件，应准确说明制作方式，不得声称实际运行了 Aseprite 软件。

## 交付前检查

已确认的特例：2026-10-21 用户要求 4 牌保持原图不变，只生成 Aseprite。因此麦乐鸡 4 保留四种形状及原始位置、方向，不应用统一图案复制或方向修正规则；转换后的合成结果必须与原图逐像素一致。

- 固定底板（含 McDonald 字样和边框）与已确认版本一致。
- 重复图案来自同一个原始素材，通过复制及必要的 180° 旋转排列。
- 图案数量、布局和朝向逐一符合模板；特别是 3 牌应为 1 个向上、2 个向下。
- 源文件保留固定底板与图案的独立图层，PNG 与源文件合成结果一致。
